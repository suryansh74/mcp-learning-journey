## What is MCP?
Model Context Protocol is an open standard that lets AI applications (Claude, Cursor, etc.) connect to external tools, data sources, and workflows in a standardized way.

Think of it as **USB-C for AI**.

## Core Concepts (to be filled as we learn)
- **Host**: The AI application (Claude Desktop, Cursor, custom app)
- **Client**: Component inside the Host that talks to servers
- **Server**: The program we build that exposes tools / resources / prompts
- **Transport**: How client and server communicate (stdio, SSE, Streamable HTTP)
